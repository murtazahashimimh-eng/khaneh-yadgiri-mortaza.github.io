# خانهٔ یادگیری مرتضی — نسخه نهایی آماده انتشار

این پروژه یک سایت استاتیک فارسی و راست‌به‌چپ است. محتوای آموزشی داخل `data/content.js` قرار دارد و با کلیک روی هر عنوان، درس واقعی با توضیح، نکته و تمرین باز می‌شود.

## انتشار عمومی
برای آدرس دائمی، این پوشه باید در یک مخزن GitHub قرار گیرد و GitHub Pages برای آن فعال شود. این بسته خودش بدون دسترسی به حساب GitHub کاربر نمی‌تواند مخزن را ایجاد یا به حساب او متصل کند.

## نکته مهم
این نسخه از ابتدا با محتوای واقعی ساخته شده و فقط فهرست کتاب یا عنوان خالی نیست. خلاصه‌ها و آموزش‌های مربوط به آثار نویسندگان، متن جایگزین کتاب‌های دارای حق نشر نیستند.
